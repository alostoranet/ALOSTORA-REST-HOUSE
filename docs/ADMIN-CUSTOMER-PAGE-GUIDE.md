# التحكم بواجهة العملاء — ALOSTORA REST HOUSE

## إظهار وإخفاء الأقسام
من برنامج التحكم افتح **إعدادات الاستراحة → واجهة العميل**.

يمكنك تشغيل أو إخفاء كل قسم بشكل مستقل:
- مكتبة الأفلام والمسلسلات.
- متابعة المشاهدة.
- الصوتيات.
- الكتب والمستندات.
- التطبيقات.
- التواصل مع الإدارة.
- لوحة الترحيب.
- شريط الإعلانات والتنبيهات.

اضغط **حفظ وتطبيق إعدادات صفحة العملاء**. تحفظ الإعدادات محلياً في ملف `customer-page-settings.json` داخل مجلد بيانات التطبيق، وتصل التغييرات إلى صفحات العملاء المفتوحة خلال دقيقة أو عند تحديث الصفحة.

إخفاء القسم لا يحذف الملفات أو بيانات المكتبة، ويمكن إعادة إظهاره في أي وقت.

## الشريط الإعلاني
من **إعدادات الاستراحة → الإعلانات** ستجد محرر الشريط الإعلاني:
1. اكتب عنواناً اختيارياً.
2. اكتب نص الإعلان.
3. اختر إعلاناً أو تنبيهاً.
4. فعّل خيار تشغيل الشريط.
5. اضغط حفظ ونشر.

يظهر النص في شريط متحرك أعلى صفحة العملاء، ويتوقف أثناء مرور المؤشر عليه. ويُحترم إعداد تقليل الحركة في الجهاز.

## النسخ الاحتياطي
تتضمن النسخة الاحتياطية الآن إعدادات ظهور أقسام صفحة العملاء بالإضافة إلى قاعدة البيانات والأغلفة والهوية والإعلان. لا تتضمن ملفات الفيديو والصوت والكتب والتطبيقات الأصلية؛ يجب نسخ مجلدات الوسائط الأصلية بصورة مستقلة.

## التصميم
تم توحيد نمط الأزرار وحقول الإدخال والجداول في برنامج التحكم مع ألوان الاستراحة الأساسية (الكحلي والأبيض والأحمر)، مع الإبقاء على تبويبات الإدارة الحالية ووظائفها.
