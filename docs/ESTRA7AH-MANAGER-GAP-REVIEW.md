## ترتيب العمل المقترح للمرحلة التالية
1. إضافة حد سرعة تنزيل اختياري، مع إبقاء تشغيل الفيديو والصوت دون تأثر.
2. إضافة إعلانات مصورة متعددة مع إدارة ترتيبها ومدة ظهورها من لوحة التحكم.
3. تطوير إحصاءات تفصيلية لكل مجلد وقرص، وإظهار حالة الأقراص غير المتصلة.
4. بناء وحدة Live TV مستقلة لمصادر IPTV/HLS ودليل القنوات وتصنيفاتها.
5. اختبار العرض الفعلي على الهاتف والكمبيوتر والتلفاز، وتجربة Range resume على Chrome وأجهزة العملاء.

لا تُحذف أي ملفات أصلية عند إخفاء الأقسام أو فك تسجيل مسارات المكتبة.
