# مراجعة الفجوات مقابل Estra7ah Manager

هذه مراجعة وظيفية وليست ادعاءً بأن كل ميزة في المنصة المرجعية موجودة بالفعل في ALOSTORA REST HOUSE.

| المجال | الحالة الحالية في ALOSTORA | الملاحظة / المتبقي |
|---|---|---|
| واجهة متجاوبة للهاتف والكمبيوتر | موجودة في صفحة العملاء | يلزم اختبار فعلي على هاتف وشاشة تلفاز قبل اعتماد الشكل النهائي |

| تبويبات المحتوى | موجودة | الرئيسية، الصوتيات، الكتب، التطبيقات؛ الأفلام والمسلسلات ضمن مكتبة واحدة |
| التحكم بإظهار/إخفاء أقسام العميل | أضيف في هذا التحديث | كل قسم رئيسي قابل للتشغيل والإخفاء من برنامج التحكم |
| شريط الأخبار/الإعلانات المتحرك | أضيف | شريط نصي متحرك، بالإضافة إلى معرض صور متعدد الشرائح بإدارة ترتيب ومدة وروابط وإظهار/إخفاء |
| مكتبة الأفلام والمسلسلات | موجودة | تصنيفات، مسلسلات، مواسم/أجزاء، حلقات، أغلفة وبيانات |
| مشغل الفيديو الداخلي | موجود | تشغيل داخل صفحة المشاهدة، مع دعم مسارات الصوت والترجمة بحسب الملف والمتصفح |

| الكتب والمستندات | موجودة | فتح/تنزيل حسب نوع الملف ودعم المتصفح |
| التطبيقات | موجودة | تنزيل مباشر للتطبيقات المفهرسة |

| البث المباشر وIPTV | مستبعد من نطاق هذه النسخة | لا توجد صفحة أو روابط أو مشغلات بث مباشر في هذا الإصدار |

| جلب الملصقات والبيانات تلقائياً | موجود جزئياً | جلب بيانات الأفلام والمسلسلات من مصادر خارجية، ثم تخزين الأغلفة محلياً |

| العمل المحلي دون MikroTik | موجود | تشغيل صفحة العملاء على الشبكة المحلية |

## ترتيب العمل المقترح للمرحلة التالية
1. تطوير إحصاءات تفصيلية لكل مجلد وقرص، وإظهار حالة الأقراص غير المتصلة.
2. بناء وحدة Live TV مستقلة لمصادر IPTV/HLS ودليل القنوات وتصنيفاتها.
3. اختبار حد السرعة والاستئناف الفعلي على Chrome، وتجربة معرض الإعلانات على الهاتف والكمبيوتر والتلفاز.

لا تُحذف أي ملفات أصلية عند إخفاء الأقسام أو فك تسجيل مسارات المكتبة.
