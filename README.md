# ALOSTORA REST HOUSE

برنامج مستقل لإدارة استراحة مشاهدة الأفلام والمسلسلات على شبكة الأسطورة نت.

## التقنية
- Windows WPF على .NET 8 لإدارة السيرفر.
- ASP.NET Core مدمج لتقديم واجهة المشاهدة وملفات الفيديو.
- SQLite ستضاف في المرحلة التالية لحفظ المكتبة وسجل المشاهدة.
- لا توجد إدارة كروت أو تجاوز Hotspot؛ MikroTik هو المسؤول عن صلاحية المشترك.

## المرحلة الحالية
النواة الأولية: واجهة ويب عربية، فهرسة ملفات الفيديو، وتقديم HTTP Range لدعم التقديم والترجيع دون تحويل لحظي.
